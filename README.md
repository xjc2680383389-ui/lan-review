# 提审台 · 局域网提审、审核与交付工具

在**同一局域网**内（同一 Wi-Fi / 路由器）完成「提交审核 → 手机/笔记本审核 → 通过后正式交付」的完整流程。不依赖公网、第三方账号或付费 API。

## 一、启动

| 设备 | 操作 |
| --- | --- |
| macOS 创作者主机 | 双击 `启动.command`（若提示无权限：终端进入本目录执行 `chmod +x 启动.command` 一次即可） |
| Windows 电脑 | 双击 `启动.bat` |

前提：设备已安装 [Node.js](https://nodejs.org)（LTS 版本即可，无需执行任何 npm 命令）。

正式交付的 HTTPS 通道还需要 OpenSSL。可安装 OpenSSL 并加入 PATH；Windows 也会自动查找 Git for Windows 常用安装目录内的 OpenSSL。缺少时审核页仍可启动，但正式交付通道不可用，控制台会说明原因。

启动后：

- 创作者页面自动打开 `http://localhost:8456/`（端口被占用时自动顺延，以窗口里打印的地址为准）
- 关闭窗口或按 Ctrl+C 即停止服务

## 二、快速上手（全图形界面，无需改任何配置）

1. **选工作区**：首次启动页面会引导选择一个文件夹作为工作区，之后项目都存放在这里，选择会被记住。
2. **新建项目**：填日期、品牌、项目名，自动创建 `日期_品牌_项目名` 文件夹；同名文件夹会明确询问是「使用现有」还是「新建带编号」，绝不静默覆盖。
3. **选文件**：在文件树里点选文件；文件夹可展开后整层选用。提交后生成 **V01、V02…独立版本快照**，之后修改工作文件不影响已提交版本。
4. **连接设备**：
   - 手机（审核）：连同一 Wi-Fi，浏览器扫码或输入 `http://主机IP:端口/join`，填 6 位连接码，选「审核设备」。
   - 笔记本（接收）：用 **HTTPS 地址** `https://主机IP:端口/join` 打开（首次浏览器提示「不安全」，点「高级 → 继续前往」——这是本机自建证书的正常提示），填连接码，选「接收电脑」。
5. **审核**（手机/笔记本浏览器上）：点开文件即可看图、放视频、听音频、看 PDF 和文本；视频支持**在当前画面位置发时间码评论**，点评论里的时间码可跳回该画面；每个文件给出「通过 / 需要修改」。评论与结论实时回到创作者页面。
6. **正式交付**：当**所有指派设备对所有文件都点了「通过」**，版本上出现红色「审核通过」章，才能把该版本原样传输给在线的接收电脑。接收端选择接收文件夹（只需选一次），逐文件传输、逐文件 SHA-256 校验，两端都显示结果与保存位置；失败可逐文件重试或重新发起。

## 三、数据存在哪里

- 工作区内的 `.lan-review/`：项目、版本快照（`versions/`）、设备、评论、审核结论、交付记录——**重启电脑后全部保留**。
- 用户主目录 `~/.lan-review/`：记住上次的工作区 + HTTPS 自签证书。
- 创作者页面仅主机本机可打开；手机/笔记本只能看到分配给自己的任务，未配对设备一律 401。

## 四、自检与测试

```
node selftest.js
```

79 项确定性自检：启动、安全门（非本机禁入创作者页、伪造 token、路径穿越、HTTP 拉取交付文件被拒）、工作区/项目/同名处理、快照不可变性、审核门（未全通过不可交付）、交付全流程（HTTPS 通道、逐文件校验、取消/重发）、配对限速、重启持久化、纯 JS SHA-256 与 Node crypto 对拍。

## 五、已知限制（如实说明）

- 接收电脑的浏览器需支持文件系统写入（Chrome / Edge 均可；Safari / Firefox 不支持，页面会明确提示）。
- 「不安全」证书警告是自建证书的正常现象（局域网工具无法申请公网证书），每台设备首次连接点一次即可。
- 音视频能否预览取决于浏览器编解码：H.264 MP4 / WAV / JPG / PNG / PDF / 文本均可；MOV/MKV 等格式会显示信息并提供下载。
- 换了 Wi-Fi（主机 IP 变化）后，设备需要用新地址重新连接（连接页重新输码即可，历史数据不受影响）。

## 六、目录结构

```
lan-review/
├─ 启动.bat / 启动.command   # 双击启动
├─ server/                   # 纯 Node 标准库实现，零 npm 依赖
│  ├─ main.js               # 入口：HTTP(审核/预览) + HTTPS(交付通道)
│  ├─ api.js                # 全部业务接口
│  ├─ store.js              # JSON 原子持久化（重启可恢复）
│  ├─ core.js               # 路由/Range 流式/SSE
│  ├─ media.js              # 哈希/快照拷贝/路径安全
│  └─ net.js                # 局域网地址 / 自签证书生成
├─ public/                   # 创作者页 + 设备页（全中文界面）
├─ selftest.js               # 79 项全链路自检
└─ scripts/make_fixtures.py  # 测试素材生成（图片/视频/PDF/xlsx/wav）
```
